# Evaluation method
Gold set in `eval/gold_questions.json`: ~30 answerable, ~10 unanswerable, 5+ supersession cases. Ground truth must come from an authoritative source (changelog, release notes, well-known design thread), recorded in `source_note`.

Systems compared on the same graph and the same LLM:
- Baseline: vector-only RAG over comments (`eval/baseline_rag.py`), no refusal, no supersession.
- IntentLens: full pipeline.

Metrics (`eval/metrics.py`): answer accuracy, supersession accuracy, refusal correctness, citation precision, calibration (mean confidence when right vs wrong), p95 latency. Keyword matching is the first pass; add an LLM judge for borderline items and report that you did.

Honest-reporting rules: do not tune on the test questions after seeing results; keep a held-out third; publish failures.
Output: `docs/EVALUATION_RESULTS.md` (generated by `make eval`).
